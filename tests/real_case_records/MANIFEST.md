# Real Case Records Manifest

This directory stores compact evidence from real or semi-real script checks. It is not a production dataset archive.

## Canonical Records

- `2026-07-02_real_phy_quant_test_record.md`: single large `PHY_QUANT` diagnostic record. The full raw `PHY_QUANT` file is intentionally not stored in the repository; only file metadata, head/tail excerpts, and checksums are kept under `inputs/`.
- `2026-07-03_demo_multi_window_test_record.md`: early 13-window CHMC/CPIHMC window-checking record for the external `../demo` dataset.
- `2026-07-10_demo_runner_dry_run_record.md`: canonical staged runner extraction record for `../demo`, stopping before TI/TST.
- `2026-07-11_demo_runner_output_review.md`: manual review of the staged runner outputs, convergence summaries, selected diagnostic plots, and discard sensitivity.
- `2026-07-11_reviewed_skiprows_execution_record.md`: reviewed per-window extraction record with user-accepted demo-only discard for `0.0` and `1.8`.
- `2026-07-11_reviewed_ti_only_record.md`: guarded TI-only record after user-confirmed integration direction, zero reference, unit conversion, and mean-force sign convention.

## Retained Attachments

- `2026-07-10_demo_runner_dry_run/convergence/*.csv`: canonical convergence-summary CSV set for the `../demo` runner screening.
- `2026-07-10_demo_runner_dry_run/convergence/_0.4.png`: representative plot for near-constant RC axis-format review.
- `2026-07-10_demo_runner_dry_run/convergence/0.0.png`: representative plot for MeanForce discard review.
- `2026-07-10_demo_runner_dry_run/convergence/1.8.png`: representative plot for initial RC-adjustment review.
- `2026-07-11_candidate_skiprows/output/*`: reviewed extraction output for the per-window discard fixture.
- `2026-07-11_reviewed_ti_only/output/*`: reviewed TI-only output, including `free_energy_profile.png`.

## Pruned Attachments

Intermediate duplicate convergence CSV directories generated by the candidate skiprows and reviewed TI-only runs were pruned after the baseline staged convergence CSVs were retained. Most per-window PNG plots were also pruned because they can be regenerated from the external `../demo` dataset and the documented runner configs.

This pruning does not remove scientific evidence required by the records: the records keep summary values, output tables, representative plots, and pointers to the configs needed to regenerate full artifacts.

Some generated `summary.json` files preserve historical child-command arguments, including `--output` paths for plots or convergence files that were later pruned. Treat those JSON command paths as execution provenance, not as the current retained-attachment inventory.

## Boundary

These records are diagnostic and regression-test evidence. They do not certify sampling convergence, production physical correctness, TST readiness, or reusable discard policies.
